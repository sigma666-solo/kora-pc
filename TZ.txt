ОБЩИЕ КРИТЕРИИ ПРОЕКТА

1. Проект должен быть выполнен с использованием HTML, CSS, JavaScript и jQuery.
2. Проект должен иметь понятный интерфейс: заголовок, основные блоки, кнопки, поля ввода и сообщения для пользователя.
3. Данные проекта должны храниться в массивах и объектах JavaScript.
4. В проекте должны использоваться переменные let и const.
5. В проекте должны использоваться условия if, else if, else.
6. В проекте должны использоваться логические и сравнительные операторы.
7. В проекте должны использоваться циклы for, while или do...while.
8. В проекте должны использоваться функции с параметрами и return.
9. В проекте должны использоваться массивы и методы работы с ними: push, splice, forEach, find, filter, sort.
10. В проекте должны использоваться объекты или массивы объектов.
11. Проект должен изменять содержимое страницы через DOM.
12. В проекте должны использоваться события click, input, change и submit.
13. В проекте должна быть хотя бы одна форма для ввода данных.
14. В форме должна выполняться проверка введённых данных.
15. В проекте должен использоваться поиск по данным.
16. В проекте должны быть минимум два варианта фильтрации данных.
17. В проекте должны быть минимум два варианта сортировки данных.
18. Для работы с интерфейсом необходимо использовать jQuery.
19. В проекте должны использоваться jQuery-методы $(), val(), text(), html(), css(), on().
20. В проекте должны использоваться addClass(), removeClass() или toggleClass().
21. В проекте должен использоваться хотя бы один эффект jQuery: fadeIn, fadeOut, fadeToggle, slideDown, slideUp или slideToggle.
22. В проекте должна быть возможность добавлять новые данные.
23. В проекте должна быть возможность удалять данные.
24. В проекте должна быть возможность изменять данные или их состояние.
25. Данные проекта должны сохраняться в localStorage.
26. Для сохранения данных необходимо использовать JSON.stringify() и JSON.parse().
27. После перезагрузки страницы сохранённые данные должны автоматически загружаться.
28. Все основные действия пользователя должны выполняться без перезагрузки страницы.
29. Проект должен содержать отдельные файлы index.html, style.css и script.js. не обязательно именно script.js этот пункт говорит, чтобы я не делал весь проект в одном файле (index.html)
30. Код должен быть разделён на небольшие функции, чтобы отдельные действия проекта выполнялись через отдельные функции.
